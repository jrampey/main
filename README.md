# Joseph Rampey — Projects

A central index of my current GitHub repositories, software projects, home infrastructure, and experiments. Each substantial project keeps its own source code, issues, releases, and detailed documentation in its own repository; this repository is the lightweight directory and landing page.

## Active Projects

### [MiSTer Audit](https://github.com/jrampey/MiSTer-Audit)

Audit, identify, organize, and safely clean up a MiSTer FPGA ROM library using No-Intro hashes and MiSTer-aware metadata.

**Status:** Active  
**Current release:** v1.4  
**Platform:** MiSTer FPGA / Bash / Python / GitHub Actions

Highlights include Fast Audit and Full Verification, No-Intro SHA-1 identification, configurable audit policy, regional completion reporting, duplicate detection, save pairing, collision-safe rename planning, integrity safeguards, library-intelligence reports, and Update All integration.

[Repository](https://github.com/jrampey/MiSTer-Audit) · [Releases](https://github.com/jrampey/MiSTer-Audit/releases) · [Issues](https://github.com/jrampey/MiSTer-Audit/issues)

## About This Repository

`main` is intentionally an index rather than the source of truth for every project. New standalone projects should generally live in their own repositories and be added here with a short description and links. This keeps releases, issues, documentation, and development history attached to the project they belong to while providing one place to see everything at a glance.

The repository directory above reflects the repositories currently owned by this GitHub account. Private repositories are identified explicitly and their links are only accessible to authorized users.
