## Active Projects

### [MiSTer ROM Library Auditor](https://github.com/jrampey/MiSTer-ROM-Library-Auditor)

Audit, identify, organize, and safely clean up a MiSTer FPGA ROM library using No-Intro hashes and MiSTer-aware metadata.

**Status:** Active  
**Current release:** v1.3  
**Platform:** MiSTer FPGA / Bash / Python / GitHub Actions

Highlights include Fast Audit and Full Verification modes, No-Intro SHA-1 identification, regional library-completion reporting, duplicate detection, save pairing, safe rename planning, integrity safeguards, Update All integration, and synthetic regression testing.

[Repository](https://github.com/jrampey/MiSTer-ROM-Library-Auditor) · [Releases](https://github.com/jrampey/MiSTer-ROM-Library-Auditor/releases) · [Issues](https://github.com/jrampey/MiSTer-ROM-Library-Auditor/issues)

## About This Repository

`main` is intentionally an index rather than the source of truth for every project. New standalone projects should generally live in their own repositories and be added here with a short description and links. This keeps releases, issues, documentation, and development history attached to the project they belong to while providing one place to see everything at a glance.
